# My Tasks 2.3.2 使用步骤

1. 保留现有 My Tasks 项目、登录权限和全部 D1 数据，原地发布更新。
2. 从 My Tasks 的会话启动页下载 `MyTasks_Chat_Bridge.zip` 并解压。
3. Chrome / Edge 扩展管理页开启开发者模式，加载包含 `manifest.json` 的解压文件夹。安装一次即可。
4. 点击任务或“和 GPT 讨论该任务”，选择聊天 / Work；新建会话在出现真实地址后自动绑定，再次点击进入原会话。成功后中间页自动关闭。
5. 删除被明确确认时，下次点击自动新建；含糊的加载故障可使用“会话已删除，重新建立”。
6. 在任务详情粘贴仓库链接，保存后点击“打开仓库”。也可以将链接发送给 ChatGPT，由工具保存。仓库入口无需辅助扩展或本机访问。

如果扩展未安装或网页控件改变，启动页保留手动打开、上下文复制和真实地址绑定入口。

部署迁移使用 `drizzle/` 内的增量迁移；2.2 增加 `task_ai_sessions`，不删除或清空历史任务、计划、复盘及设置。
