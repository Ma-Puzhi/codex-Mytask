# My Tasks V2.3.1 使用说明

原来的 [My Tasks](https://mytask.example) 已原地更新。现有任务、复盘、计划、仓库链接及会话绑定保留，不需要重新创建网站。

## 本次修复

选择聊天或 Work 后，在新的标签页打开任务会话。确认会话打开且绑定已保存后，自动关闭本次启动的中间页，保留 My Tasks 主页面和聊天 / Work。

- 已绑定会话直接确认并关闭中间页，避免重复保存造成等待。
- 同一任务重复点击产生的中间页统一关闭。
- 绑定保存失败时保留中间页，可以重试。
- 已被用户导航回 My Tasks 的标签页不会被误关。

## 三个文件

| 文件 | 用途 |
| --- | --- |
| `My_Tasks_V2.3.1.zip` | 完整项目源码，供备份及后续原地更新 |
| `My_Tasks_V2.3.1_使用说明.md` | 本说明 |
| `MyTasks_Chat_Bridge_V2.3.1.zip` | Chrome / Edge 浏览器辅助插件，含自动打开、绑定和关闭中间页逻辑 |

浏览器插件与 ChatGPT 中的 My Tasks 插件是两个入口：前者负责浏览器里的任务会话；后者继续使用原有的 My Tasks，不需要另建一个插件。

## 更新已经安装的浏览器插件

1. 解压 `MyTasks_Chat_Bridge_V2.3.1.zip`，里面的 `MyTasks_Chat_Bridge` 文件夹包含 `manifest.json`。
2. 将这个文件夹里的文件复制到原来加载扩展的文件夹，替换旧版本文件。
3. 打开 Chrome 的 `chrome://extensions` 或 Edge 的 `edge://extensions`，找到 **My Tasks · Chat / Work Bridge**，点击重新加载按钮。
4. 刷新 My Tasks，然后点击聊天或 Work。扩展管理页应显示版本 **2.3.1**。

如果原来的扩展文件夹已经丢失，移除旧扩展，再加载这次解压出的文件夹。不要同时启用两份相同扩展。

## 第一次安装浏览器插件

1. 解压浏览器插件 ZIP。
2. 打开浏览器的扩展管理页，开启开发者模式。
3. 点击“加载已解压的扩展程序”，选择包含 `manifest.json` 的 `MyTasks_Chat_Bridge` 文件夹。
4. 保持 ChatGPT 登录，回到 My Tasks 选择聊天或 Work。

## 仓库链接

任务详情只保留仓库链接、保存链接和打开仓库。也可以将仓库链接发给 ChatGPT，让它保存到对应任务。仓库入口不需要浏览器辅助插件、本机 Git 或本地文件访问。

## 项目源码的用途

解压完整项目 ZIP 可以查看代码、数据库增量迁移和测试。用 Sites 更新时，要求依据 `sites/SITE_BUILD_PROMPT.md` 原地更新已有 My Tasks，复用 `.openai/hosting.json` 的项目身份和私人访问权限，不创建第二个网站、不清空 D1 数据。

## 验证范围

启动页关闭、重复启动页清理、主页面与原生会话保留、失败重试，以及原有任务数据的回归检查已通过。真实账号的浏览器自动化没有在你的本机远程实测；本次浏览器修复需要加载或重新加载 2.3.1 扩展后生效。
