# My Tasks 任务会话辅助扩展

1. 解压 `MyTasks_Chat_Bridge.zip`。
2. 在 Chrome 打开 `chrome://extensions`，或在 Edge 打开 `edge://extensions`。
3. 开启“开发者模式”，点击“加载已解压的扩展程序”，选择包含 manifest.json 的文件夹。
4. 回到 My Tasks，点击任务或“和 GPT 讨论该任务”，选择聊天或 Work。

新任务会打开 ChatGPT，并发送该任务的上下文。原生会话地址出现后自动回写绑定；再次选择同一模式会打开同一个会话。聊天和 Work 分别绑定。确认打开且绑定保存成功后，会自动关闭本次启动的中间页，并保持聊天 / Work 标签页为当前页。

关闭聊天 / Work 标签页不等于删除对话，下一次选择仍进入同一个地址。中间页提前关闭时，扩展保留新会话地址，下一次打开时补写绑定。请更新到 2.3.2；替换原扩展文件后，在扩展管理页点击重新加载，保留原扩展可继续使用已有本地绑定。

扩展仅对 My Tasks 发起的会话传递上下文。持久保存的是任务 ID、模式、会话地址、更新时间和待回写标记；待发送的上下文只在浏览器临时会话存储中保留。不会读取密码、Cookie、令牌，也不调用私有 ChatGPT API。

删除处理：扩展观察到已绑定会话的删除确认后，下一次点击会重新创建。明确的“会话不存在/已删除”错误也会触发重建。登录失败、网络错误或“无法加载会话”不会被当作删除，因此不会自动覆盖原绑定。若在其他设备删除且页面只显示含糊的加载错误，请使用模式弹窗中的“会话已删除，重新建立”。

ChatGPT 的网页控件可能更新。若自动发送未成功，页面会提示登录/发送，保留新会话页并发送已填入的上下文即可自动记录地址。若会话页面没有出现可识别的持久地址，绑定会保留原值，不伪造成功。
