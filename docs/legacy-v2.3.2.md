# My Tasks 2.3.2

保留现有每日任务、长期任务、晚间复盘和休息日界面。点击任务或“和 GPT 讨论该任务”后选择聊天 / Work，在新的标签页打开；任务右侧 `•••` 仍进入详情。

## 任务会话

聊天与 Work 按任务分别绑定，真实会话地址保存在 D1。首次点击创建会话并携带任务上下文，再次点击进入原会话。会话确认打开且绑定已保存后，自动关闭本次启动的中间页，保留原 My Tasks 和聊天 / Work。确认会话已删除时重新创建；登录或网络故障不会覆盖原绑定。无法明确判断的删除可勾选“会话已删除，重新建立”。

原生会话的创建、发送和地址回写由 `companion/` 浏览器辅助扩展完成；不使用 OpenAI API、API Key 或私有 ChatGPT 接口。一次安装方式见 `companion/README.md`。网站提供 `/downloads/MyTasks_Chat_Bridge.zip`，未安装时显示安装步骤及手动绑定入口。ChatGPT 网页控件改变时自动操作可能需要调整。

## 仓库链接

任务详情只保留仓库链接输入框、保存链接及打开仓库按钮。可以将 GitHub、GitLab、Gitee 或其他 HTTPS 仓库链接发送给 ChatGPT，由 `set_task_repository_link` 保存到对应任务。点击按钮直接在新标签页打开仓库，无需浏览器辅助扩展、本机访问、Git 安装或仓库操作授权。

已移除创建仓库、上传、提交、推送、拉取、分支、差异、公开性和本机目录配置入口。原有仓库链接继续显示，历史 Git 元数据仍保留在数据库中。

## 数据与接口

- D1 为任务、事件、原文复盘、设置及会话绑定的权威数据源，所有操作按登录用户隔离。
- `task_ai_sessions` 使用 `(task_id, mode)` 主键；兼容原有聊天和 AI 工作区记录，迁移只增加表。
- `/`：需要登录的任务控制台；`/launch`：独立标签页的任务会话启动页。
- `/api/tool/:name`：需要登录且同源的任务操作；`/mcp`：ChatGPT 插件工具及任务界面。
- 扩展持久缓存包含会话地址、更新时间、待回写标记和明确删除记录，待发送上下文使用临时会话存储。关闭标签页不会清除绑定；提前关闭中间页时，下次启动会恢复尚未回写的会话地址。

更新时复用 `.openai/hosting.json` 中的原项目及私人访问权限，不创建第二个网站，不清空旧数据。

## 检查

- `node tests/task-launch.mjs`：实际 SQL 迁移、独立任务 / 模式绑定、权限隔离、旧数据、仓库链接、移除旧 Git 启动动作和删除后重建规则。
- `node tests/companion-background.mjs`：模拟 Chrome API 检查关闭会话页、中间页及扩展重启后复用相同 URL，删除后重建、来源验证和中间页关闭。
- `node tests/companion-chat.mjs`：首条消息已在 DOM 中时恢复绑定，重开已有会话不重复发送上下文。
- `tests/mytasks-v21.test.mjs`：保留原数据、长期任务、Git 元数据和任务界面路由的回归检查。
- `node tests/launcher-close.mjs`：启动页在绑定保存后主动关闭、已绑定会话快速关闭、保存失败时保留页面。
- TypeScript、相关 ESLint 和生产构建。

上述自动检查不等于真实账号的浏览器端到端验证；原生 ChatGPT / Work 的自动发送需要安装扩展后验证。
